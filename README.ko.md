# TimeMaker

[English documentation](README.md)

TimeMaker는 macOS 메뉴바에서 동작하는 네이티브 Pomodoro Timer입니다. SwiftUI와 AppKit으로 구현했으며 Electron, 내장 브라우저, 원격 서비스는 사용하지 않습니다.

## 주요 기능

- 메뉴바에서 실시간 `MM:SS` 카운트다운 표시. `90:00`처럼 한 시간이 넘는 시간도 분 단위로 표시합니다.
- 기존의 단일 닫기 버튼을 유지하는 독립형 컴팩트 타이머 창.
- 이전에 사용한 활동 라벨을 유연하게 매칭하고, 사용 빈도순과 키보드 선택을 지원하는 자동완성.
- 1~60 범위로 설정 가능한 스크롤 기준값과 분·초 개별 스크롤 조절(분 4배, 초 2배).
- 5, 10, 15, 30, 60, 90분 프리셋.
- 일시정지·재시작과 절대 종료 시각 기반 계산. Mac 잠자기와 앱 재실행 후에도 시간이 복원됩니다.
- 오늘의 집중 도트. 꽉 찬 원 하나는 한 시간이며, 창 좌측 오버레이 그리드에 세로 최대 8개까지 표시합니다.
- 최근 7일 그래프, 활동별 비중, 연속 기록, 요약 카드와 최근 세션을 제공하는 로컬 분석.
- 시스템/Light/Dark 화면 모드.
- macOS 네이티브 로그인 항목 등록과 선택 가능한 Mac 기본 알림음 완료 알림.
- 영어·한국어 UI 현지화.

## 요구 환경

- macOS 14 Sonoma 이상
- `v1.0.2` 배포 파일은 Apple Silicon(`arm64`)용
- 소스 빌드 시 Xcode 15.3 이상, Swift 5.10 이상

## 설치

현재 컴퓨터에는 `/Applications/TimeMaker.app`으로 설치됩니다.

GitHub 릴리스에서 설치하려면:

1. 비공개 GitHub 릴리스의 `TimeMaker-1.0.2-macOS-arm64.zip`을 내려받습니다.
2. 압축을 풀고 `TimeMaker.app`을 `/Applications`로 옮깁니다.
3. 최초 실행 시 Gatekeeper 확인이 나타나면 앱을 Control-클릭한 뒤 **열기**를 선택합니다.
4. macOS가 요청하면 알림을 허용합니다. 소리는 선택 사항이며 Mac의 기본 알림음을 사용합니다.

빌드 Mac에 Apple Developer 서명 인증서가 없어 릴리스는 ad-hoc 서명했습니다. 로컬 코드 서명 검증은 완료했지만 Apple 공증(notarization)은 받지 않았습니다.

## 사용법

- TimeMaker를 실행하면 타이머 창이 열립니다. 이후 메뉴바 카운트다운을 좌클릭하면 타이머 창을 열거나 닫습니다.
- 메뉴바 카운트다운을 우클릭하면 타이머를 바로 시작·일시정지·재시작합니다.
- 타이머가 정지된 상태에서 분 또는 초 숫자 위를 스크롤해 시간을 바꿉니다. 분은 최솟값과 최댓값에서 순환하지 않습니다.
- 분석 아이콘 왼쪽의 초기화 버튼을 누르면 실행 중인 타이머를 취소하고 설정 시간으로 돌립니다.
- `work`, `Reading`, `Writing` 같은 활동을 입력하면 이전 라벨이 사용 빈도순으로 나타납니다. 위·아래 화살표로 선택하고 Enter로 확정하거나 마우스로 클릭할 수 있습니다.
- 재생 버튼으로 시작합니다. **타이머 시작 시 윈도우 숨기기**가 켜져 있으면 패널이 닫히고 메뉴바 카운트다운만 남습니다.
- 패널을 다시 열어 일시정지하거나 재시작합니다.

타이머가 완료되어도 마지막 활동 라벨을 유지합니다. 빈 라벨 상태로 타이머 창을 닫으면 설정한 기본 라벨을 사용합니다. 처음 설치하면 `work`, `30:00`으로 시작합니다.

## 설정

| 설정 | 기본값 | 범위 / 선택지 |
| --- | --- | --- |
| 스크롤 기준값 | 5 | 1~60, 분은 4배·초는 2배 적용 |
| Mac 로그인 시 열기 | 켬 | 켬 / 끔 |
| 타이머 시작 시 윈도우 숨기기 | 켬 | 켬 / 끔 |
| 초기화한 시간도 분석에 포함 | 끔 | 켬 / 끔 |
| 기본 라벨 | `work` | 비어 있지 않은 라벨 |
| 다크 모드 | 시스템 | 시스템 / Light / Dark |
| 알림 허용 | 켬 | 켬 / 끔, macOS 네이티브 알림 |
| 알림 소리 허용 | 끔 | 켬 / 끔, Mac 기본 알림음 |

## 데이터와 개인정보

TimeMaker에는 계정, 분석 SDK, 텔레메트리, 네트워크 의존성이 없습니다. 타이머 기록과 라벨 사용 횟수는 다음 위치에만 저장됩니다.

```text
~/Library/Application Support/TimeMaker/history.json
```

설정과 복구 가능한 활성 타이머 상태는 macOS 표준 환경설정 도메인 `com.jaewone.timemaker`에 저장됩니다.

## 빌드와 테스트

```bash
swift test
./scripts/build_app.sh
./scripts/install_app.sh
./scripts/package_release.sh
```

빌드 결과는 Git에서 제외된 `dist/`에 생성됩니다. 데이터 흐름과 구현 경계는 [아키텍처 문서](docs/ARCHITECTURE.ko.md)를 참고하십시오.
