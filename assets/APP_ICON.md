# App icon source

The final source bitmap is `TimeMaker-AppIcon.png`; `TimeMaker.icns` and the files under `AppIcon.iconset/` are derived assets.

The bitmap was generated with OpenAI's built-in image generation tool using `main.png` only as a color and mood reference. No text or third-party mark is included.

Prompt:

> Create a polished square native macOS app icon for a Pomodoro timer named TimeMaker. Center a simple abstract timer face that also suggests making or shaping time. Use a pale cool-gray background, soft mint accents, and deeper teal details. Keep it calm, crisp, readable at 16 px, and free of letters, numbers, words, watermarks, UI screenshots, and third-party marks.
