# TimeMaker 아키텍처

[English documentation](ARCHITECTURE.md)

## 실행 구조

TimeMaker는 다음 네이티브 macOS 프레임워크로 구성한 메뉴바 전용 앱(`LSUIElement`)입니다.

- `MenuBarController`: `NSStatusItem`, 실시간 텍스트, 좌클릭 타이머 창 토글, 우클릭 시작·일시정지·재시작 동작을 관리합니다.
- `MainPanelController`: 기존 단일 닫기 버튼을 사용하는 독립형·이동 가능한 borderless `NSPanel`을 관리합니다.
- `WorkspaceWindowController`: 분석·설정이 공유하는 `NSWindow`와 사이드바 이동을 관리합니다.
- 세 화면은 SwiftUI로 그리고, 메뉴바와 윈도우 동작은 AppKit으로 제어합니다.

## 타이머 상태 흐름

`TimerStore`가 정지·실행·일시정지 상태의 단일 진실 공급원입니다. 실행 중에는 카운터를 단순 차감하지 않고 종료 시각을 권위 값으로 저장합니다. 250ms UI ticker는 종료 시각으로부터 표시할 정수 초를 계산합니다. 이 방식은 시간 오차를 막고 화면 잠자기, 시스템 잠자기, 프로세스 재실행 뒤에도 타이머를 복구합니다. 분 조절은 지원 범위의 양 끝에서 멈춥니다. `ScrollWheelMonitor`는 0.5×, 1×, 2×, 3×, 4×, 5×의 이산 감도 중 하나로 실제 이동을 누적한 뒤 별도로 설정한 타이머 단위를 적용합니다. 분에는 2배의 감도가 추가로 적용됩니다. 정지 상태에서는 항상 조정할 수 있고, 기본값이 꺼진 활성 타이머 설정을 켜면 실행·일시정지 중에도 스크롤로 시간을 바꿀 수 있습니다. 활성 상태의 스크롤 변경은 실행 중인 종료 시각 또는 일시정지된 남은 시간과 현재 세션의 기록용 계획 시간에 함께 반영됩니다.

같은 AppKit 모니터는 타이머가 활성 상태일 때 분 또는 초 숫자의 클릭도 받습니다. 기본값이 켜진 클릭 연장 설정은 실행 중인 종료 시각 또는 일시정지된 남은 시간에 설정 가능한 1~60분을 더합니다. 이 경로는 `plannedDurationSeconds`를 의도적으로 유지하므로 클릭으로 추가한 시간은 완료 세션과 초기화 시간 분석에서 제외됩니다. 스크롤 조정은 별도 경로이며 인식된 증감분만큼 `plannedDurationSeconds`를 계속 바꿉니다.

저장 상태에는 다음 값이 포함됩니다.

- 단계와 설정 시간
- 일시정지 세션의 남은 시간
- 실행 세션의 종료 시각
- 활동 라벨과 최초 시작 시각
- 일시정지 전까지 누적한 활성 시간
- 클릭으로 연장된 남은 시간과 분리한 기록용 계획 시간

완료 시 세션을 정확히 한 번 기록하고, 설정에 따라 네이티브 알림을 보냅니다. 소리가 켜져 있으면 내장 `Glass.aiff` 차임을 직접 재생하고, 알림을 클릭하면 타이머 창을 다시 엽니다. 카운트다운은 설정 시간으로 돌아가지만 마지막 라벨은 유지합니다. 사용자가 초기화하면 설정 시간으로 돌아가며, 그때까지의 활성 시간은 관련 설정이 켜져 있을 때만 세션으로 기록합니다.

## 영속화

`HistoryStore`는 Application Support에 버전이 명시된 JSON을 원자적으로 교체 저장합니다. 완료 세션과 정규화한 라벨 사용 횟수가 들어갑니다. 기간별 초기화는 선택한 프리셋 범위에 종료 시각이 들어가는 완료 세션만 삭제하며, 저장한 라벨 자동완성은 유지합니다. 환경설정과 활성 타이머 복구 상태는 `UserDefaults`를 사용합니다.

라벨의 동일성은 공백·하이픈·밑줄과 영어 대소문자를 정규화해 판단합니다. 자동완성은 그 정규화 값을 이용해 부분 문자열을 매칭하고 사용 횟수, 최근 사용 시각, 라벨 순으로 정렬합니다.

## 분석

`AnalyticsBuilder`는 저장 세션을 입력받는 순수 `TimeMakerCore` 변환입니다. 최근 7일의 일별 합계, 활동별 합계, 활동일 평균, 현재 연속 기록을 계산합니다. `AnalyticsView`는 Swift Charts와 네이티브 요약 카드로 결과를 표시합니다.

## 시스템 연동

- `SMAppService.mainApp`으로 로그인 항목을 등록하거나 해제합니다.
- `UNUserNotificationCenter`는 완료 알림을 표시하고 기본 클릭 동작을 타이머 패널로 연결합니다. 선택한 내장 `Glass.aiff` 차임은 알림 소리 권한과 무관하게 `NSSound`로 재생합니다.
- `NSAppearance`로 시스템, Light, Dark 선택을 모든 창에 적용합니다.

## 패키징

Swift Package Manager로 실행 파일을 빌드합니다. `scripts/build_app.sh`는 표준 `.app` 구조를 만들고 현지화 파일과 `.icns`를 복사한 뒤 ad-hoc 서명과 번들 검증을 수행합니다. `scripts/package_release.sh`는 GitHub Release에 올릴 버전 ZIP과 SHA-256 파일을 생성합니다.
