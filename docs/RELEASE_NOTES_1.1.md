# TimeMaker 1.1

TimeMaker 1.1 adds README screenshots, publishes the project under GPL-3.0, and includes the latest timer controls and lavender visual theme.

## Highlights

- Removed the standalone Analytics toolbar icon; Analytics remains available from the More menu.
- Changed the soft green accent palette to a similarly light lavender purple.
- Added an opt-in setting for scrolling to add or remove time from the current running or paused timer. The default is off.
- Added English and Korean README screenshots using repository-local assets.
- Published the repository under the GNU General Public License v3.0.
