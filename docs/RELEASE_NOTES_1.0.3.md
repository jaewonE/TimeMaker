# TimeMaker 1.0.3

TimeMaker 1.0.3 corrects scroll sensitivity and adds the requested completion and history-management behaviors.

## Highlights

- Each accepted scroll now changes time by one unit. Scroll distance—not the time increment—is scaled: minutes require 4× and seconds require 2× the base movement.
- The compact timer restores matching vertical spacing between the label, timer, and playback control, with a resized panel.
- When enabled, timer completion plays the Mac system alert sound directly. Clicking a completion notification opens the timer window.
- Settings can clear completed timer records from one of eight preset periods: 1 day, 3 days, 1 week, 1 month, 3 months, 6 months, 1 year, or all time. The action requires confirmation and keeps saved labels.

---

TimeMaker 1.0.3은 스크롤 감도 동작을 바로잡고 완료 알림 및 기록 관리 기능을 보완합니다.

## 주요 내용

- 스크롤이 인식될 때마다 시간은 1단위만 바뀝니다. 시간 증감 폭이 아니라 스크롤 이동 거리를 조정하며, 분은 기준 거리의 4배, 초는 2배가 필요합니다.
- 라벨, 타이머, 재생 버튼 사이의 세로 간격을 맞추고 컴팩트 타이머 창 크기를 조정했습니다.
- 알림 소리가 켜져 있으면 완료 시 Mac 시스템 알림음을 직접 재생합니다. 완료 알림을 클릭하면 타이머 창이 열립니다.
- 설정에서 1일, 3일, 일주일, 한 달, 3개월, 6개월, 1년, 전체 중 하나를 선택해 완료 기록을 확인 후 삭제할 수 있습니다. 저장한 라벨은 유지됩니다.
