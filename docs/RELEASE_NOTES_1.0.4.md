# TimeMaker 1.0.4

TimeMaker 1.0.4 separates timer increment from scroll sensitivity again and makes the sensitivity control easier to read.

## Highlights

- The timer increment setting is restored: each accepted scroll changes the chosen number of minutes or seconds.
- Scroll sensitivity is a horizontal, discrete control with exactly six choices: 0.5×, 1×, 2×, 3×, 4×, and 5×. Its default is 1×, and minutes apply an additional 2× sensitivity.
- Completion sound now uses the built-in `Glass.aiff` chime.

---

TimeMaker 1.0.4는 타이머 증감 단위와 스크롤 감도를 다시 분리하고 감도 조절을 더 직관적으로 만듭니다.

## 주요 내용

- 인식된 스크롤마다 분 또는 초를 몇 칸 바꿀지 정하는 스크롤 단위 설정을 복원했습니다.
- 스크롤 감도는 0.5×, 1×, 2×, 3×, 4×, 5× 중 하나만 선택하는 가로 이산 슬라이더입니다. 기본값은 1×이며 분에는 2배의 감도가 추가로 적용됩니다.
- 완료음으로 내장 `Glass.aiff` 차임을 사용합니다.
