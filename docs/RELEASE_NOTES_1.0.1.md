# TimeMaker 1.0.1

TimeMaker 1.0.1 refines the daily timer flow without changing its local-only data policy.

## Highlights

- Right-click the menu-bar timer to start, pause, or resume directly.
- Use the new reset control to cancel an active timer and restore its configured duration. Elapsed active time is recorded only when enabled in Settings.
- The timer is now an independent compact borderless window, retaining its single custom close control.
- Labels now normalize spaces, hyphens, underscores, and English case; autocomplete supports Up/Down and Return as well as mouse selection.
- Configure the fallback label (default: `work`), and closing an empty label restores it cleanly.
- Refined the compact light-mode UI with a `#F5F5F5` background and a smaller playback control.

---

TimeMaker 1.0.1은 로컬 전용 데이터 정책을 유지하면서 일상적인 타이머 흐름을 다듬었습니다.

## 주요 내용

- 메뉴바 타이머를 우클릭하면 바로 시작·일시정지·재시작합니다.
- 새로운 초기화 버튼으로 활성 타이머를 취소하고 설정 시간으로 되돌릴 수 있습니다. 경과 활성 시간은 설정에서 허용했을 때만 기록됩니다.
- 타이머가 단일 사용자 정의 닫기 버튼을 유지하는 독립형 컴팩트 borderless 창이 되었습니다.
- 라벨은 공백·하이픈·밑줄과 영어 대소문자를 정규화합니다. 자동완성은 마우스뿐 아니라 위·아래 화살표와 Enter도 지원합니다.
- 기본 라벨(기본값: `work`)을 설정할 수 있으며, 빈 라벨로 창을 닫으면 자연스럽게 복원합니다.
- `#F5F5F5` 라이트 배경과 더 작은 재생 컨트롤로 컴팩트 UI를 다듬었습니다.
