# TimeMaker 1.0.0

TimeMaker's first release is a fully native SwiftUI/AppKit Pomodoro timer for the macOS menu bar.

## Highlights

- Live menu-bar countdown and compact reference-matched timer panel
- Minute/second scrolling, 5–90 minute presets, and pause/resume
- Activity-label autocomplete ranked by usage frequency
- Today progress dots with partial-hour angle rendering
- Seven-day and activity analytics stored entirely on the Mac
- Login-item integration, silent native notifications, and System/Light/Dark modes
- English and Korean interface and documentation
- Deadline-based timing and running-state recovery across sleep or app restart

## Install

The attached build requires macOS 14 or later and Apple Silicon. Extract the ZIP, move `TimeMaker.app` into `/Applications`, then Control-click and choose **Open** on first launch if Gatekeeper asks. The build is ad-hoc signed and locally verified, but not Apple-notarized because no Developer ID identity was available.

Use the attached `.sha256` file to verify the download.
